# Installateur MSI Windows 10/11 — Plan d’implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (recommended) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produire un package Windows 10/11 x64 installable sans intervention technique, avec prérequis vérifiés, conservation des données et désinstallation sûre.

**Architecture:** Conserver l’EXE PyInstaller et l’installateur Inno Setup existants comme secours. Ajouter un package MSI WiX et un bootstrapper WiX Burn qui installe/valide WebView2, déploie l’EXE, crée les raccourcis et laisse `%LOCALAPPDATA%\SEL Facturation` intact pendant les mises à jour et désinstallations.

**Tech Stack:** Python 3.12, PyInstaller, WiX Toolset 4, Burn, WebView2 Evergreen Bootstrapper, GitHub Actions Windows.

**Spec:** `AGENTS.md`, `Docs/CODEX_HANDOFF.md`, cible Windows 10/11 x64 confirmée par le demandeur.

## Global Constraints

- Ne pas remplacer Python/Flask/SQLite ni modifier le schéma existant sauf migration additive.
- Préserver les bases SQLite, snapshots PDF, sauvegardes et l’export `sel-facturation-portable` v1.
- Ne jamais supprimer `%LOCALAPPDATA%\SEL Facturation` pendant une mise à jour ou désinstallation.
- Garder l’EXE/Inno Setup comme voie de secours jusqu’à validation du MSI sur le poste SEL.
- Aucun statut GO commercial sans installation, mise à jour, lancement et impression vérifiés sur le poste cible.

## Review Focus

- WebView2 absent : le bootstrapper doit l’installer ou produire une erreur explicite et récupérable.
- Installation sans privilèges élevés : les fichiers applicatifs peuvent être installés par utilisateur, sans écraser les données.
- Mise à niveau depuis Inno Setup : même application, données et anciens PDF conservés.
- Désinstallation : retirer l’application et les raccourcis, conserver les données métier et sauvegardes.
- Windows 10/11 hors ligne : l’installateur doit utiliser le package WebView2 embarqué ou documenter clairement la limite.
