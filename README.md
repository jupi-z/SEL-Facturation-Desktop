# SEL Facturation Desktop

Application locale de facturation de la Société d'Énergie du Lualaba (SEL).

Le code source, la documentation de lancement, les tests et les scripts de création de l'exécutable Windows seront ajoutés ici.

> Les décomptes PDF du logiciel ne sont pas des factures normalisées DGI authentifiées. Les règles tarifaires et fiscales doivent être validées par SEL avant tout usage.
